# 三国 · AI 驱动的叙事创作项目

## 设计目标

用 AI 作为核心创作引擎，打造一部**三国背景下的科幻故事**——披着玄幻外衣的硬科幻。

项目遵循**先剧本、后游戏**的路线：优先产出完整的、有代入感的叙事内容，剧本成熟后再考虑游戏化。前期尽量减少甚至消除游戏界面的设计负担，全部精力集中在剧情质量上。

核心理念：**创作者自己先玩嗨了，才会有真正有趣的内容。**

## 主要组成部分

### 1. 角色系统

每个角色由人类设计基础画像，再交给独立的 AI 实例驱动：

- **个性**与**语言风格**
- **属性**：武力、智力、体力等（参照光荣三国志体系）
- **人物背景故事**、所属势力与敌对势力
- **对话和行动案例**（2-3 个示例，用于 AI 角色校准）

限制条件：
- 没有角色是无敌的
- 没有角色是不会死的
- 没有角色是不会犯错的
- 可以有超自然能力，但是要有限制和代价

### 2. 场景系统

场景是角色碰撞的舞台，需包含：

- **地理风貌**
- **时间点**：赤壁之战之后的任意时间
- **当时已发生的关键历史事件**
- **场景附近的人文风貌**
- **环境细节描写**（2-3 个细节示例）

### 3. AI 多角色互动流水线

这是项目的核心机制：

```
人类设计角色 + 场景
        ↓
   导演 AI（剧本AI）
   安排角色进入场景
        ↓
   每个角色由独立 AI 驱动
   角色之间自由互动
        ↓
   导演 AI 记录情节流动
        ↓
   审阅 AI 打分评估
        ↓
  ┌─────┴─────┐
  低分 → 砍掉重来   可接受 → 根据反馈优化再跑
                    高分 → 暂留，后续串联
        ↓
   人类筛选、编排
   串成完整故事
```

### 4. 内容产出

- `content/` — 章节文本（如 `chapter-000.md` 序章）
- 角色档案（待建）
- 场景档案（待建）

## 接下来的工作

1. **角色创建**：各自准备 1-2 个角色的完整画像（个性、属性、背景、对话示例）
2. **场景设计**：确定第一个场景的地理、时间、人文与环境细节
3. **导演 AI 搭建**：设计"导演"角色的 prompt，使其能编排角色进入场景并记录互动
4. **多角色互动测试**：将 3-4 个角色投入场景，观察碰撞效果，反复调整
5. **审阅机制**：建立 AI 评分体系，对生成内容进行筛选与优化
6. **第一个完整案例**：产出一段经过多轮优化、人类认可的叙事片段
