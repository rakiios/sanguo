# Attribute System

| 分值范围 | 含义 | 对标 |
|----------|------|------|
| 96-100 | 当世绝顶，传说级别 | 吕布武力、诸葛亮智力 |
| 80-95 | 一流，天下知名 | 关羽武力、周瑜智力 |
| 60-79 | 优秀，郡县级名士/猛将 | 普通名将、谋士 |
| 40-59 | 普通兵卒/士人水准 | |
| 20-39 | 低于常人 | |
| 1-19 | 几乎没有此项能力 | |

## Five Core Attributes

- **武力**: 战斗能力，包括近身搏杀、兵器娴熟度、气力运用
- **智力**: 分析、推理、谋划能力，包括洞察力和学习速度
- **体力**: 耐力、生命力、承受伤害和疲劳的能力
- **魅力**: 人格感染力、领导气质、说服和感召他人的能力
- **政治**: 权谋手腕、资源调配、势力经营的能力

## Notes

- Main characters (like 林一) should NOT have extreme stats — room to grow is part of the narrative
- Supernatural abilities are reflected in narrative descriptions, not raw attribute numbers
- Attributes can shift over the course of the story (injury, training, awakening)
- 百分制提供更细的区分度，同品级角色之间可以有微妙差异
