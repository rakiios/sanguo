# 技能系统架构

------------------------------------------------------------------------

## 一、设计理念

技能系统遵循以下核心原则：

1.  无职业系统。
2.  所有人物均可学习所有技能。
3.  技能成长模拟现实学习逻辑。
4.  属性影响学习效率与表现效果。
5.  联动技能由熟练度自然触发。
6.  战斗能力拆分为"基础能力"与"工具熟练度"。

本系统强调：后天成长可弥补先天差异。

------------------------------------------------------------------------

# 二、五维基础属性体系

五维属性彼此正交，不发生功能重叠。

## 1. 武力

定义：直接物理输出能力。

影响内容：

-   战斗伤害强度
-   武器控制能力
-   爆发力
-   压制能力

代表：打得多狠。

------------------------------------------------------------------------

## 2. 智力

定义：认知与分析能力。

影响内容：

-   学习速度
-   战术判断
-   逻辑推理
-   情报解读能力

代表：看得多清。

------------------------------------------------------------------------

## 3. 体力

定义：身体承载与耐久能力。

影响内容：

-   生命值上限
-   疲劳抗性
-   受伤承受能力
-   持续行动能力

代表：撑得多久。

------------------------------------------------------------------------

## 4. 魅力

定义：情绪感染与人格影响能力。

影响内容：

-   说服成功率
-   领导效果
-   团队士气稳定
-   社交影响力

代表：别人愿不愿意跟你。

------------------------------------------------------------------------

## 5. 权略

定义：权力结构运作能力。

影响内容：

-   资源调度效率
-   势力经营能力
-   阵营博弈判断
-   利益分配能力
-   权谋操作成功率

代表：能否在复杂人际结构中掌控局势。

------------------------------------------------------------------------

# 三、技能分类结构

技能分为两大类：

1.  战斗类技能
2.  实用类技能

所有技能均具备：

-   熟练度（0--100）
-   经验值（XP）
-   维护与轻微衰减机制

------------------------------------------------------------------------

# 四、战斗类技能（重构结构）

## 1. 战斗基础

核心战斗能力，与武器无关。

包含：

-   徒手搏斗
-   格挡闪避
-   距离控制
-   出手节奏
-   战斗体能分配
-   临场反应

提供：

-   基础命中率
-   基础闪避率
-   基础伤害值
-   战斗体力消耗效率

属性权重：

-   武力：0.40
-   体力：0.25
-   智力：0.20
-   权略：0.10
-   魅力：0.05

------------------------------------------------------------------------

## 2. 兵器使用

泛技能结构，内部按武器类别独立成长。

武器类别示例：

-   刀剑类
-   枪矛类
-   弓弩类
-   重兵器类
-   特殊器械类

提供：

-   武器额外伤害加成
-   武器专属动作解锁
-   武器耐久损耗降低
-   特殊效果触发概率

属性权重：

-   武力：0.50
-   智力：0.20
-   体力：0.20
-   权略：0.05
-   魅力：0.05

------------------------------------------------------------------------

## 3. 战术协同

团队作战能力。

影响：

-   连携触发概率
-   队伍整体受伤率
-   协同技能发动成功率

属性偏向：

-   智力
-   权略
-   魅力

------------------------------------------------------------------------

## 4. 战场意识

局势判断与战场决策能力。

影响：

-   先手概率
-   识破埋伏能力
-   目标优先级判断
-   战斗误判概率降低

属性偏向：

-   智力
-   权略
-   少量武力

------------------------------------------------------------------------

# 五、实用类技能

包括但不限于：

-   生存采集
-   医疗护理
-   锻造修造
-   机关工艺
-   侦察潜行
-   谈判说服
-   领导组织
-   经营调度
-   权谋操作

各技能独立成长。

------------------------------------------------------------------------

# 六、技能成长机制

技能成长来源：

1.  训练（稳定增长）
2.  实践（风险较高但收益较高）
3.  教学（在导师辅助下加速成长）

属性影响：

-   学习速度
-   技能表现效果

当前规则：

属性不限制技能上限。 低属性角色可通过长期训练达到高熟练度，但成长更慢。

------------------------------------------------------------------------

# 七、战斗计算框架

战斗表现 =

战斗基础 × 武器系数 × 情境修正

其中：

武器系数 = 1 + 武器熟练度加成

情境修正包含：

-   战术协同
-   战场意识
-   联动技能

------------------------------------------------------------------------

# 八、联动技能系统

当多个技能达到指定熟练度时自动解锁。

示例：

战斗基础 ≥ 70 枪矛类熟练 ≥ 60 → 解锁「破阵冲锋」

侦察 ≥ 60 权谋操作 ≥ 60 → 解锁「暗线布局」

医疗 ≥ 60 战斗基础 ≥ 50 → 解锁「战地急救」

联动技能通过使用成长，不可直接训练。

------------------------------------------------------------------------

# 九、系统特征总结

-   无职业限制
-   可自由转型
-   成长逻辑贴近现实
-   属性结构清晰正交
-   易扩展
-   易实现
-   支持剧情驱动
-   支持 AI 角色成长模型

------------------------------------------------------------------------

# 十、说明

技能系统包含：

-   战斗结构重构（战斗基础 + 兵器使用）
-   属性优化（政治 → 权略）
-   五维正交模型定型
-   联动技能机制建立
-   现实成长模型确立

本版本已具备实际实现基础，可进入数值细化阶段。
