# 风格指南

> 本文档定义叙事创作的语言风格和写作规范。
> 与 `worldbuilding.md`（世界观）互补，本文档关注"怎么写"而非"写什么"。

---

## 一、叙事声音

### 1. 里世界对话 — 偏古风白话文

优雅、符合三国时代特征。

- 称呼：阁下、公、君、某、仆
- 动词：敢请、叨扰、见笑、殊死
- 语助词：乎、矣、邪、哉（适度，不堆砌）

> **示例**："将军此行凶险万分，某虽不才，愿为前驱。"

### 2. 观者独白 — 技术隐喻

用古风/工匠隐喻包装技术思维，严禁直接使用现代计算机术语。

> **示例**：他凝视那道裂隙——像一幅画卷上被利刃刮去一层颜料。经纬尚在，纹路已然扭曲。

### 3. 表世界

仅在后期揭露后启用，届时另行定义。当前创作阶段无需关注。

## 二、隐喻替代系统

里世界叙事中，科幻概念必须通过隐喻表达：

| 科幻概念 | 里世界隐喻 |
|----------|------------|
| 代码/逻辑 | 经纬、纹路、机括、韵律、草蛇灰线 |
| Bug/错误 | 裂隙、败笔、污渍、生硬、打结 |
| 系统/世界 | 画卷、大阵、天道、樊笼 |
| 延迟/卡顿 | 神魂滞后、粘稠、脱节、残影 |
| 数据溢出 | 墨色洇开、噪点、狂乱色彩 |
| 算力/能量 | 气数、心力、神思 |
| 能量场/修为外显 | 气运、气势、威压 |
| 力量结构/数据流 | 气机经纬、力道脉络、劲力轨迹 |

> **示例**：
> - 科幻原文："他检测到系统中出现了一个严重的 bug，导致数据溢出"
> - 里世界改写："他瞥见画卷经纬之中有一处败笔，周遭墨色已然洇开"

### 核心术语定义

以下术语在里世界叙事中反复出现，需统一理解：

- **气运**：品级能量的外在表现，常人可感知的"威压"或"气势"。高品级武将身上有明显气运流转，普通人或无品者则无此征兆。观者能看到气运的更深层结构
- **气机经纬**：力量流动的底层脉络，只有观者能看到。类比为世界的"源代码骨架"，包含节点、流向、断裂点等结构信息
- **气数**：天道分配给个体或势力的能量配额，与算力/资源分配对应。"气数已尽"即资源耗竭

## 五、写作约束

### 看破 ≠ 胜过

观者能看到世界的缝隙，但凡人肉体往往无法承受干预的反作用力。应安排能力使用失败的情节来体现世界的残酷与变数。

### 系统疏离感

系统信息是"诅咒"和"干扰"，而非便捷的金手指。每章不超过 1 次出现，以诡异化形式呈现（视觉噪点、幽蓝光斑、生理反应）。

### 表世界信息的渗透控制

前期严禁出现明确的科幻术语或系统提示。表世界的暗示只能通过感官异常（梦境、既视感、生理不适）传递，不能通过对话或旁白直接点明。
