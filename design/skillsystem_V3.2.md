# 技能系统架构 V3.2（现实成长整合版）

> 本版本在 V3.1 稳定性修正版基础上，整合最早期"现实学习模型"设计。
> 目标：形成一个完整、统一、可落地、可扩展的终版结构雏形。
> 本文档为完整整合版本，而非差异补丁。

------------------------------------------------------------------------

# 一、核心设计哲学

技能系统遵循以下底层逻辑：

1.  无职业系统。
2.  人人可学习所有技能。
3.  成长模拟现实过程：习得 + 练习 + 记忆保持。
4.  属性只影响学习效率与表现强度，不强制锁死路径。
5.  技能通过熟练度自然成长。
6.  联动技能由"熟练度门槛 + 组合行为"自然形成。
7.  技能输出对接十品能量体系。
8.  技能存在代价与超限风险。
9.  系统长期稳定、可扩展。

------------------------------------------------------------------------

# 二、技能成长模型（现实学习机制）

技能 = 习得 + 练习 + 记忆保持

每个技能统一结构：

-   熟练度（0--100）
-   XP（经验值）
-   档位稳定品级（对接十品体系）
-   使用代价
-   超限阈值

## 2.1 XP 来源

1.  训练（稳定、慢、可控）
2.  实战 / 实践（高波动、高收益、带风险）
3.  教学 / 带徒（双向收益，受属性影响）

所有技能均可通过实践获得经验，但效率不同。

## 2.2 记忆保持与衰减

-   80+ 熟练度启用轻微衰减。
-   衰减只影响稳定率与效率，不降低档位。
-   最近使用获得临时稳定加成。

------------------------------------------------------------------------

# 三、五维属性体系

-   武力
-   智力
-   体力
-   魅力
-   政治

属性正交：

-   武力 = 物理压制
-   智力 = 认知分析
-   体力 = 身体承载
-   魅力 = 情绪影响
-   政治 = 权力结构运作

------------------------------------------------------------------------

# 四、技能分类体系（精简而完整）

## 4.1 战斗类技能

-   近战搏斗
-   兵器使用
-   远程射击
-   格挡闪避
-   战场意识
-   战术协同
-   （可选）气力运用

> 每个角色通常主修 1--3 项即可。

## 4.2 实用类技能

-   生存采集
-   烹饪与处理
-   医疗护理
-   锻造修造
-   机关与工艺
-   侦察潜行
-   谈判说服
-   领导组织
-   经营调度
-   权谋操作

技能尽量少而精，覆盖战斗、生存、生产、社交、治理。

------------------------------------------------------------------------

# 五、属性权重卡机制

每个技能都有一张属性权重卡（总和=1），用于计算学习速度与表现效率。

示例：

近战搏斗： 武力 0.50 / 体力 0.30 / 智力 0.10 / 魅力 0.05 / 政治 0.05

战场意识： 智力 0.45 / 武力 0.20 / 政治 0.20 / 体力 0.10 / 魅力 0.05

谈判说服： 魅力 0.50 / 智力 0.25 / 政治 0.20 / 体力 0.03 / 武力 0.02

经营调度： 政治 0.45 / 智力 0.35 / 魅力 0.15 / 体力 0.03 / 武力 0.02

医疗护理： 智力 0.45 / 体力 0.25 / 政治 0.15 / 魅力 0.10 / 武力 0.05

属性决定学习快慢与效率，但不强制上限封顶。

------------------------------------------------------------------------

# 六、技能效果设计原则

每个技能仅提供 1--2 个核心收益：

-   成功率
-   消耗效率
-   风险控制

避免大量被动叠加。

示例：

锻造修造高 → 材料浪费降低、耗时缩短。\
战术协同高 → 连携触发率提升、队伍受伤率降低。

------------------------------------------------------------------------

# 七、联动技能系统（自然觉醒机制）

联动不是点出来的，而是"长出来的"。

## 7.1 联动类型

1.  组合技（动作联动）
2.  领域专精（效率标签）
3.  叙事联动（剧情选项）

## 7.2 基础联动规则

-   2技能联动：A≥60 且 B≥40
-   3技能联动：A≥70 且 B≥50 且 C≥30

联动也有熟练度，成长缓慢。

## 7.3 联动稳定品级（V3.1规则继承）

联动品级 = min(参与技能稳定品级)

若参与技能达到档位中段 → 可 min + 1（仍受超限限制）

------------------------------------------------------------------------

# 八、熟练度与十品体系对接

## 8.1 稳定品级映射

  熟练度    稳定品级
  --------- ----------
  0--9      未入品
  10--19    九品
  20--29    八品
  30--39    七品
  40--49    六品
  50--59    五品
  60--69    四品
  70--79    三品
  80--89    二品
  90--100   一品

档内熟练度影响稳定率与消耗效率。

------------------------------------------------------------------------

# 九、技能资源与超限机制

## 9.1 三资源结构

-   体力
-   精神
-   能量

主/次资源规则继承 V3.1。

## 9.2 超限判定

基础： （智力 + 体力） × 熟练度系数

第三属性按类别修正：

-   战斗 → 武力
-   权谋 → 政治
-   社交 → 魅力

------------------------------------------------------------------------

# 十、专注槽（Focus）机制

为限制泛滥掌握：

-   每角色拥有 N 个主练槽（建议3）。
-   主练技能成长更快。
-   非主练成长减缓。

角色可转型，但需要时间成本。

------------------------------------------------------------------------

# 十一、系统整体特征

-   自然成长路径
-   技能非按钮化
-   联动真实生成

-   可长期平衡
-   可扩展性强
